①
AIブログ作成ツール
月額 5,000円前後
機能フロー
サロン基本情報入力 → メニュー・強み入力 → テーマ提案（AI） → ブログ本文生成（AI） → SNS投稿文生成（AI） → LINE配信文生成（AI） → 確認・編集・出力
必要データ
サロン名・住所・コンセプト メニュー一覧・価格 スタッフ情報 HPBページ情報（補完用）
ポイント：AIが担当するのはほぼ全工程。必要データの大半が「店舗入力」なので、リクルート依存度は低い。既存の申込書セルフチェックAIとロジックが近い。⑥の「ブログ更新催促」機能の出力部分として統合できる。
②
ホットペッパー改善AI
月額 9,800円前後
機能フロー（ペチちゃん案を補完）
HPB URL入力 → 自店情報スクレイピング → 競合店スクレイピング → 自店解析（AI） → 競合比較（AI） → 改善案生成（AI） → 定期再解析（スケジューラ） → レポート出力
必要データ
HPB掲載情報（公開ページ） 競合店HPBページ 閲覧数・予約転換率 検索順位データ
⚠️ 要注意：スクレイピングで取れる「掲載内容の見た目」は公開情報だが、閲覧数・予約CV・検索順位はリクルート提供データ。これがないと「改善提案」の根拠が薄くなる。既存スクレイパーで代替できる範囲の精査が必要。
③
AI写真診断
月額 3,000円前後
機能フロー
HPBページから写真取得 → 画像解析（AI Vision） → 明るさ・構図・印象評価（AI） → 競合写真と比較（AI） → 改善ポイント・撮影構図提案（AI） → レポート出力
必要データ
HPB掲載写真（公開） 競合店掲載写真（公開）
ポイント：必要データがすべて公開情報なので、リクルート依存度ゼロ。ただし画像解析にVision系APIが必要（コスト要確認）。単体商品より⑥の診断機能として組み込む方が自然。
④
AI競合分析
月額 9,800円前後
機能フロー
競合サロンURL登録 → 定期スクレイピング（スケジューラ） → 前回データとの差分検出 → 変更内容の分類・解釈（AI） → 自店への影響推論（AI） → LINE / メール通知
必要データ
競合HPBページ（クーポン・写真・メニュー） 競合GBP情報 監視対象サロンURL
ポイント：差分検出自体はAI不要（単純比較）。AIが効くのは「この変化が何を意味するか・自店にどう影響するか」の推論部分のみ。リクルート依存なし。⑥の入力データとして機能する。通知基盤（LINE等）の実装コストに注意。
⑤
AIクーポンメーカー
月額 5,000円前後
機能フロー
施術名・ターゲット入力 → 現在のクーポン入力（任意） → クーポンタイトル複数生成（AI） → キャッチコピー生成（AI） → 説明文生成（AI） → 既存クーポン改善提案（AI） → 選択・コピー出力
必要データ
施術名・価格・ターゲット 既存クーポン文（改善用） 競合クーポン事例（参考用）
ポイント：①と同様にリクルート依存なし。ほぼ全工程AIで完結。シンプルなので単体でも成立するが、②や⑥の「クーポン改善」出力部分として統合する方が価値が高い。
⑥
AIサロンパートナー ★本命
月額 9,800円前後
機能フロー（ペチちゃん案を補完）
各種データ取得（自店・競合・GBP） → 前回との差分検出 → KPI判定（AI） → 問題抽出（AI） → 優先順位づけ（AI） → 改善施策の推論・根拠生成（AI） → LINE等で通知
必要データ
HPB掲載情報・写真・クーポン 競合HPBページ 口コミ数・評価（HPB内部） GBP情報（Google Business Profile API） 売上・予約数（店舗入力） 目標KPI（店舗設定）
⚠️ 最重要確認事項：口コミ数・評価はHPBの公開ページに表示されているため、リクルート提供データに頼らずスクレイピングで取得できる可能性がある。ただし利用規約の商用利用条項の確認が必須。GBP APIはペチちゃんが調査予定。売上・予約数は店舗側から入力してもらう設計にすれば代理店終了後も継続可能。
🔍 次フェーズ：ペチちゃん担当 外部データ調査項目
① HPBのスクレイピング：利用規約上の商用利用可否
② Google Business Profile API：取得可能情報・利用条件・コスト
③ HPB口コミ・評価：公開情報としての取得可否
④ 予約・CV数：代替取得手段の有無
⑤ LINE Messaging API：通知機能実装コスト概算
